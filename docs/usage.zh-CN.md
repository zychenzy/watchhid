# 用法

WatchHID 是仅手表应用。指针、点击、表冠滚动和系统听写都不需要 iPhone 应用。操作者测试是在 Apple Watch Ultra 2 上进行的；其他型号尚未验证，本文没有宣称它们不受支持，也不提供保证。配对的 iPhone 仍可能是 watchOS 本身、或安装时所用开发者通道需要的。

## 触控板

- 拖动以移动指针。
- 轻点为左键点击。
- 长按为右键点击。
- Digital Crown 使用已有的鼠标滚轮字段做垂直滚动。它在已聚焦的触控板上、用通用 Digital Crown 即可，而不是 Ultra Action 按钮。

仅在 WatchHID 位于前台且屏幕亮起时发送输入。手表休眠或回到表盘后，请重新打开应用。设置页和系统文本输入页会暂停触控板、松开已按下的按键，并丢弃排队中的移动和滚轮事件。回到触控板后，请开始一个新的手势。

## 离开应用

只有当 WatchHID 在前台打开时，它才会作为蓝牙鼠标进行广播。离开应用后（按下数码表冠、回到表盘或手表休眠），应用会松开仍按住的按键，停止广播，并移除自己的 HID 服务。大约三秒以内的短暂打断不会让它停止。系统听写页打开期间，以及听写文本发送期间，应用会在有限时间内保持连接。

再次打开 WatchHID 时，它会重新广播，主机会重新连接；在触控板显示就绪之前可能需要稍等片刻。离开应用不会删除配对，macOS 也可能暂时保留它那一侧的蓝牙链路，不保证物理链路会立即断开。这一行为没有电量实测数据支撑。

## 输出设备

报告每次只发给**一个**已订阅的主机。在设置里，已订阅的主机会被列为 Device 1、Device 2，以此类推。这些编号会跟随同一次连接，它们不是 Mac 或 iPhone 标签；Watch 无法可靠判断对方的操作系统。

选定设备后，点 Test，或在触控板上拖动，并观察那台主机。**Ready** 只表示所选主机已经订阅，并不表示你已经看到指针移动。

如果已保存的设备不在，而且只有另一台主机已连接，会临时使用那台主机，直到你再次选择，或已保存的设备回来。如果列表里有不止一台主机、而你分不清哪台是哪台，先选 Device 1 测试，再试 Device 2。

## 英语键盘和听写

英语键盘 HID **默认关闭**。打开它会添加一个单独的键盘服务，不会改变基线鼠标 Report Map。

如果出现 Keyboard Setup Assistant，请把它关闭。WatchHID 不需要完成这项识别，也不应该用另一把键盘来识别它。没有官方保证可以阻止该助理出现。

底部的麦克风按钮会弹出**系统**文本输入界面（`presentTextInputController`，`allowedInputMode: .plain`）。`.plain` 表示可来自听写或建议的可输入文本，不含表情。它**不会**强制该页面以听写方式打开。初始输入方式由系统选择；可能先出现键盘或 Scribble。如果是这样，请使用系统页面上的输入方式控件（通常在右下角），并选择麦克风。

你用系统的 Done 控件接受结果后，在键盘 HID 已打开时，可输入的英语会被键入到 Mac 上当前焦点所在的字段。Watch 上不会显示捕获的文本。中文和其他非 ASCII 字符会被跳过。正在发送文本时，该按钮可以取消这次发送。

Watch 上的信息听写和 Siri 听写是另外的系统功能。它们不能证明 WatchHID 的输入页一定会打开在麦克风上。

## 设置

设置包括暂停触摸、英语键盘开关、输出选择，以及听写和键盘的简短说明。正常的 Watch 界面里没有扫描、日志或测试清单控制台。如果设备上存在诊断文件，它们留在应用容器内，并不是对外的日志导出。
